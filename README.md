# Catalog-Z - Pixel-Perfect Website Clone

A responsive, pixel-perfect clone of the **Catalog-Z** (TemplateMo 556) website. This project was developed as part of a frontend layout assignment to practice advanced semantic HTML structures, custom responsive CSS styling, and efficient item positioning using **Flexbox**.
## ✨ Features
- **100% Responsive Design:** Smooth transition across Mobile, Tablet, and Desktop screens.
- **Flexbox Navigation:** Clean and flexible header nav items.
- **Custom Search Banner:** Perfectly aligned search inputs over a dynamic fluid background.
- **Interactive Grid System:** Photo catalog utilizing Flexbox wrapping with custom hover effects (`effect-ming`).
- **Semantic HTML5:** Structured markup using `<nav>`, `<main>`, `<figure>`, and `<footer>`.

## 🛠️ Tech Stack Used
- HTML5
- CSS3 (Flexbox Layout Module & Media Queries)
- Font Awesome Icons (v6.x)
- Google Fonts (Roboto)
